# 轮询时间与管理设备数量
- 轮询不等式：N>=T/DELTA
	- N--被轮询的代理数（被管理设备设备数）
	- T--轮询间隔
	- DELTA--单个轮询需要的时间
- DART 与下列因数有关：
	- （1）管理站生成一个请求报文的时间
	- （2）从管理站大到代理的网络延迟
	- （3）代理处理一个请求报文的时间
	- （4）代理产生一个响应报文的时间
	- （5）从代理到管理站的网络延迟
	- （6）管理站处理一个响应报文的时间
	- （7）为了得到需要的管理信息，交换请求/想响应报文的数量

# 网际管理协议五大标准
- ISO：            CMIS/CMIP 公共管理信息服务规范
- 基于 TCP/IP:  简单网络管理协议：SNMPv 1-3
- 基于局域网： 远程监控网络 RMON-1 和 RMON -2
- IEEE 制定：    基于物理层和数据链路层 CMOL
- ITU-T:            电信网络管理标准 TMN
# RMON
- 监视网络通信情况的设备叫**网络监视器（moniter）或网络分析器（analyzer）、探测器（probe）**等
- 定义了 ==管理信息库 RMON MIB-II（流量信息）与 SNMP MIB(设备信息)
- 目标：监视子网范围内通信，从而减少管理站和被管理站系统之间的==通信负载==
# SNMP 和 RMON 区别
SNMP 设备级监控和管理功能，适合==快速部署和基础管理==
RMON：网络级监控和分析功能，适合深入的==流量分析和性能优化==
