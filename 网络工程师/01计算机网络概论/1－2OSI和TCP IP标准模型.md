# 为什么要分层？
- 模块化设计：某一层改动不影响其他层
- 产业协同
- 技术迭代
- 兼容性
# OSI
- 分层结构：
    - 应用层：应用程序/协议（HTTP/FTP 等）
    - 表示层：语法转换、数据压缩解压、加密解密（高频考点）
    - 会话层：创建/注销会话
    - 传输层：端到端传输（可靠/不可靠）
    - 网络层：逻辑寻址（IP 地址）、路由选择
    - 数据链路层：帧封装、点到点传输、差错控制
    - 物理层：比特流传输、电气规约
# TCP IP
- 应用    telent ftp  tftp  snmp...
- 传输  tcp udp
- 网络  ip icmp ospf..
- 数据链路 ethernet frame－relay
- 物理  双绞线、光纤、跳线/尾纤...
