| 参数错误类型                                 | 故障现象                                           | 简要说明                                                                 |
| -------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------- |
| **Router-ID 重复**                       | 邻居震荡、路由条目混乱，无法正常形成 Full 邻接                     | Router-ID 是 OSPF 路由器唯一标识，冲突会导致 LSA 异常，OSPFv3 同样必须手动保证 Router-ID 唯一华为 |
| **两端区域号不一致**                           | 无法建立邻居，丢弃 Hello 报文                             | 直连链路两端接口必须属于同一个 Area，区域 ID 不匹配直接丢弃 Hello 包华为                         |
| **区域类型不一致（一端 Stub/NSSA，另一端普通区域）**      | 邻居无法达到 Full 状态                                 | Stub、NSSA 区域标记必须两端完全一致，否则 LSA 交互异常                                   |
| **Hello/Dead 计时器两端不一致**                | 邻居反复震荡，一会出现一会消失                                | Hello 时间必须相同；Dead 默认是 Hello 的 4 倍，两端必须一致，否则超时判定邻居 Down华为             |
| **认证配置不一致（认证模式 / 密钥不匹配，一端开认证一端没开）**    | 丢弃 Hello 报文，邻居无法建立                             | 支持区域认证、接口认证，类型（明文 / MD5/HMAC-SHA）和密钥必须一致华为                           |
| **接口网段 / 子网掩码不一致（广播型网络）**              | 无法建立邻居，Hello 报文被拒收                             | 广播网络下 OSPF 校验 Hello 携带的子网掩码；P2P 网络不校验掩码，但仍建议同网段                      |
| **OSPF 网络类型两端不一致**                     | 邻居可以到达 2-Way，但无法进入 Full，路由缺失                   | 例如一端 Broadcast，一端 P2P；DR/BDR 选举机制不同，DBD 报文交互异常，LSA 无法完整交换            |
| **接口 MTU 不匹配**                         | 邻居停滞在**ExStart 状态**，卡在交换 DBD 报文阶段              | 华为默认不检测 MTU；Cisco 默认检测 MTU，MTU 不一致会卡住邻接关系，无法交换 LSA，学不到路由             |
| **network 宣告错误 / 掩码反掩码写错、接口未宣告进 OSPF** | 邻居无法建立；或者邻居正常，但该接口网段不发布进 OSPF 域                | network 命令使用反掩码，接口 IP 不在 network 范围内，接口不会发送 Hello，不加入 OSPF 进程        |
| **接口配置为 Silent-Interface（静默接口）**       | 该接口不再发送 Hello 报文，无法在该接口建立 OSPF 邻居；但该网段路由仍然可以发布 | 静默接口用于终端网段，禁止发送 Hello；如果互联接口误配 silent，邻居起不来                          |
| **开销 cost 配置错误**                       | 邻居正常、LSA 正常，但路由选路不符合预期，次优路径                    | 接口 cost 人为修改错误，SPF 计算得到错误最短路径                                        |
| **ACL 拦截 OSPF 组播 224.0.0.5/224.0.0.6** | 收不到 Hello 报文，邻居无法建立                            | OSPF 依靠组播收发报文，ACL 拒绝组播报文，邻居无法发现                                      |
| **ABR 区域配置错误，非骨干区域没有连接 Area0**         | 域间路由无法传递，非骨干区域外部路由丢失                           | OSPF 规则：所有非骨干区域必须直接连接骨干 Area0，否则 LSA3 类域间路由不生成                       |
