# 虚拟化
- 提高资源利用率
- 一虚多
- 多虚一
	- 堆叠
	- M－lag（跨设备链路聚合）
- 根系统
	- 默认存在，对虚拟系统进行管理
- 虚拟系统
	- 命令
		- vsys en
		- vsys name
		- switch vsys
		- assign interface g 1/0/0(分配虚拟系统资源，把这个接口分给这个虚拟系统)
	- 虚拟接口
		- 虚拟系统之间通信的接口
		- 由先后顺序，每个系统的虚拟接口为 v 1 开始向后排
		- 虚拟接口不需要同一网段
			- 考试要求配置 ip，实际不配置也能通信
			- 
		- 如果虚拟系统有物理线路连接就不需要虚拟接口
- 路由
	- 虚拟系统中没有目的网段的路由，网络不会通
	- 直接在根系统中配置
	- route static vpn instance  x.x..x vpn instance
		- 如果下一跳不是 vpn instance 那么只能在虚拟系统中配置
