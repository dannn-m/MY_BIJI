# VRRP
- 开启此功能的路由器会发vrrp 通告报文
- 形成 VRRP 组的条件
	- vrid 一致
	- vrrp 认证通过
- 角色
	- master
	- backup
- 主备选举：
	- VRRP 优先级
	- 物理 ip 地址
- 联动：
	- 当一个设备的一个接口故障后他的另一个接口任然是主角色
	- 但是下行链路不通
	- 可以将上下行链路绑定，联动 BDF 来解决
- 当 vrrp 选举成功后会发送免费 arp 报文
	- 可以刷新二层的 mac 地址表
	- 抢占后会等待一个抢占延迟才能正常工作
# 双机热备
- 防火墙开启 vrrp 功能就是 双击热备
- 条件：两防火墙配置一样，只支持两台设备做双击热备
- 关键组件：
	- VRRP、VGMP、HRP 
- VGMP:
	- 组VRRP 管理协议
	-  VRRP 的状态由 VGMP 决定
		- avtive
		- standby
	-  自动充当 VRRP 的联动功能
		- 会自动降低链路的 VRRP 优先级，实现主备切换
- HRP
	- 在防火墙中如果在发完请求包后设备故障
		- 回复包只能回复到新的 active 设备上
		- 由于防火墙的会话创建机制
			- 首包命中策略创建会话
		- 新的 active 设备无法转发回复包
	- 这是华为的独立备份协议（协议与会话等）
		- 心跳接口：必须加入安全区，配置 IP 地址
		- 只能在配置主设备进行设备配置
