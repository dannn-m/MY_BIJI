# 快速收敛
- I－SPF（增量最短路劲优先算法）、PRC、智能定时器、LSP 快速扩散

# LSP 快速扩散
- 正常情况：收到更优的 lsp，先进行计算收敛再扩散
- 快速扩散：先扩散，在 ISIS 进程中敲 flash flood
# 等价路由
- 与 ospf 原理一致，可以现在负载分担下等价路由的最大数量
- 可以设置优先级影响选路，越小越优先 **nexhop** *ipaddress* **weigh** *value* 
- 当等价路由条目大于 max
	- 优先级小优先
	- 下一设备的 system id ，小的优先
	- 本地接口小的优先

	- 与L 1 区域 id 一致，L 2 区域 id 不一致
