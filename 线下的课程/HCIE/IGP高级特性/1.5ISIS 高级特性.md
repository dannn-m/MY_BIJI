- 快速扩散：先扩散，在 ISIS 进程中敲 flash flood
# 等价路由
- 与 ospf 原理一致，可以现在负载分担下等价路由的最大数量
- 可以设置优先级影响选路，越小越优先 **nexhop** *ipaddress* **weigh** *value* 
- 当等价路由条目大于 max
	- 优先级小优先
	- 下一设备的 system id ，小的优先
	- 本地接口小的优先
# 缺省路由
- L 1 设备生成默认路由的条件：ATT＝1 的 LSP
- L 1－2 下发 ATT＝1 LSP 的条件
	- 他有 L 1 邻居与 L 2 邻居
	- 与L 1 区域 id 一致，L 2 区域 id 不一致
- ISIS 的开销
	- 一台设备更改了所有设备都要改变
	- 分为窄度量与宽度量，窄的最大只有 63
	- costtype wide
- 在 L 1－2 设备上敲 attached－bit advertise ？
	- 可以强制它不下发 att 为 1 的 lsp
- 在 L 1 上配置 att  avoid－learning
	- 收到了也不生成默认路由
- 手动下发
	- default－route－advertise always
	- 在 L 1－2 设备敲了 att advertise never 的话即时敲了手动下发也不会成功下发
	- 所以在 L 1－2 没必要手动下发给 L 1
