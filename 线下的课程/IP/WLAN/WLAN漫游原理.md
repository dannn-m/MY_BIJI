- 概述
	- sta 在不同 ap 覆盖范围移动保存用户业务不中断
	- 实现漫游必须使用相同的 SSID 和安全模板，认证模板和认证方式和认证参数也要配置相同
	- 漫游策略主要解决以下问题
		- 避免认证时间过长导致丢包甚至业务中断
		- 保证用户授权信息不变
		- 保证用户 ip 不变

	- FAC （Foreign AC）：后关联的 AC
