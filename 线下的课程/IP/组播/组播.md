# 组播 ip
- 同组播网络不同业务需要使用不同的组播 ip 地址

|                                                    |                                    |
| -------------------------------------------------- | ---------------------------------- |
| 范围                                                 | 含义                                 |
| 224.0.0.0—224.0.0.255                              | 为路由协议预留的永久组地址                      |
| 224.0.1.0—231.255.255.255233.0.0.0—238.255.255.255 | Any-Source 临时组播组地址（ASM，任意源组播）      |
| 232.0.0.0—232.255.255.255                          | Source-Specific 临时组播组地址（SSM，指定源组播） |
| 239.0.0.0—239.255.255.255                          | 本地管理的 Any-Source 临时组播组地址（私有域，不跨公网） |
