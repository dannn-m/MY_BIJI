# 介绍
- 形成分发树的方法
	- 将成员位置事先告诉某台组播路由器（Rendezvous Point，RP），形成 RPT（RP Tree）
	- 组播源先将数据已单播方式发送给 RP，RP 再将其已组播方式发送
	- 对于部分次优组播转发路径，PIM－SM 能自动优化为最优路径
