# Snoping
- 交换机对于组播报文的处理都默认广播方式
- 对于不是组成员的链路会浪费带宽
- 开启 Snoping，可以只在需要的端口转发（组播 mac 需要不一样）
## 实现
使能 snooping 的交换机有两种端口角色：路由器端口，成员端口
- 当交换机收到普遍组查询报文，交换机会将其识别为路由器端口
- 当接口收到成员关系报告报文，接口成为成员端口
	- 因此交换机需要避免主机被抑制，防止其不被识别为成员端口
	- 交换机就会收到端的报告报文后将其截获，不发往其他端口
	- 由于不抑制所有主机都会认为自己是 last reportor，离开时都会发送离开报文
	- 交换机也会把后续的特定组查询报文转发给之前记录的成员端口
