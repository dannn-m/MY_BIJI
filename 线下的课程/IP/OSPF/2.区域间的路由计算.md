# 角色
- IR：区域内路由器
- ABR：区域 0 与其他区域连接
# 区域间路由信息传递
- 由 ABR 产生，用于向一个区域通告到达另一个区域的路由
- link State ID：路由的目的网络地址
- 在一个区域内传递时信息信息不做改变
	- 路由器计算路由表时计算开销，本路由器到 ABR 的 cost＋3 类 lsa 中的 cost
# 区域间路由防环机制
- 多区域：OSPF 要求所有非骨干区域必须与 area 0 直接相连，区域间路由需经由区域 0 中转
- ABR 不会将到达某个区域内网段路由的 3 类 LSA 再注回该区域
- 双 ABR 环境：ABR 从非骨干区域收到的 3 类 LSA 不能作用于区域间路由计算
# 虚链接及其配置
-  当区域 0 切割（不连续）或者不是所有区域都与骨干相连接时需要配置虚链路功能
- 他使得逻辑上区域 0
