- 通过五类 lsa 传递路由信息
	- ls ID：目的网段的地址
	- adv ：宣告该 lsa 的 router id
		- 由于跨区域的路由器不知道该 router id 的路由信息（因为三类 lsa 也仅仅传递了路由信息）
		- 就需要四类 lsa 来标识 ASBR 的位置（在 ASBR 区域外的区域进行泛洪）
			- ls id：ASBR 的 router id
			- adv ：ABR 路由器的 router  ID
# OSPF 外部路由的两种度量类型
- Metric－Type－1：当外部路由开销与内部路由开销相当且当外部路由的开销计算方式与 ospf 网络开销具有可比性时使用（例如 ospf 互相引入）
- 它的开销为内部开销与外部开销之和
- Metric－Type－2：当 ASBR 到 AS 之外的开销远远大于 AS 之内叨叨 ASBR 的开销时，可以认为路由的可信程度较低
- 计算方式为只计算外部开销
