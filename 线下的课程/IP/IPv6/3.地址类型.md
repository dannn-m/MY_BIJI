# 地址类型
- 单播地址：标识一个接口
- 组播地址：标识多个接口
- 任播地址：标识一组网络接口，这些接口地址相同，主机访问相同地址的目的时采用最近原则，将数据发送到最近的目的
- 没有定义广播地址
# 常见的单播地址
## GUA
> global unicast Address 全球单播地址，也被称为可聚合全球单播地址，该地址全球唯一，用于需要有互联网访问需求的主机，相当于公网地址

全局路由前缀 ：有提供商指定给一个组织机构，一般至少为 48 bit
子网 id：组织机构根据自身网络需求划分子网
接口标识 ：用来标识一个设备的接口

## ULA
> Unique Local Address，唯一本地地址是私网地址，只能够在内网中使用，在公网中不可被路由，因此不能直接访问公网

![[Screenshot_2026-11-15-16-09-23-38_769977972775e0c6b41aa3dfaf766445.jpg]]
- 唯一本地地址使用 FC 00:：/7 地址块，目前仅使用了 FD 00/8 地址段。FC 00:：/8 预留为以后拓展使用
- ULA 虽然只在有限范围内有效，但也具有全球唯一前缀（虽然随机产生但是冲突概率很低）
## LLA
> 链路本地地址，有效范围为链路本地，前缀 FE 80:：/10

![[Screenshot_2026-11-15-16-14-52-63_769977972775e0c6b41aa3dfaf766445.jpg]]
- 单一链路通信，如无状态自动配置，邻居发现
- 每个接口都需要一个链路本地地址。华为设备支持自动生成和手工指定两种方式
# 组播地址
> FF:：/8

![[Screenshot_2026-11-15-16-19-09-17_769977972775e0c6b41aa3dfaf766445.jpg]]
- flags:0000 表示永久组播地址（协议使用）
	- 0001 临时使用
- scope：组的范围
- group ID：组播组 id
# 组播 MAC
- 前 16 为 33:33 后 32 位为 ipv 6 组播地址直接映射而来
- 被请求节点组播地址：
	- 当一个节点具有了单播或任播地址，就会生成一个请求节点组播地址并加入这个组播组
	- 主要用于邻居发现几张和地址重复检测功能
	- 有效范围为本地链路
