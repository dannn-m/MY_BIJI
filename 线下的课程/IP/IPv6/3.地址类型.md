# 地址类型
- 单播地址：标识一个接口
- 组播地址：标识多个接口
- 任播地址：标识一组网络接口，这些接口地址相同，主机访问相同地址的目的时采用最近原则，将数据发送到最近的目的
- 没有定义广播地址
# 常见的单播地址－GUA
> global unicast Address 全球单播地址，也被称为可聚合全球单播地址，该地址全球唯一，用于需要有互联网访问需求的主机，相当于公网地址

全局路由前缀 ：有提供商指定给一个组织机构，一般至少为 48 bit
子网 id：组织机构根据自身网络需求划分子网
接口标识 ：用来标识一个设备的接口

@bitfield
128
0-2: "001" "3 bit\n 格式前缀"
3-47: "全局路由前缀" "45 bit"
48-63: "子网 ID" "16 bit"
64-127: "接口标识" "64 bit"
note bottom 0-63 : 网络部分(64 bit)
note bottom 64-127 : 主机部分(64 bit)
@endbitfield
