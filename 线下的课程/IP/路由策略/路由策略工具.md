# filter－policy
- 在距离矢量路由协议中，设备之间传递的是路由信息，如果需要对这总路由信息进行某种过滤可以使用 filter－policy 实现
- 分为出向和入向进行实施
- 对于链路状态路由协议，他只能过滤路由无法过滤 lsa，生效于路由表生成时
- isis 与 ospf 都是在进程视图进行配置，import 为加入路由表时的过滤策略
- export 为对已==引入==的路由在向外发布时进行过滤
# Router－policy
- 用于过滤路由信息，以及为过滤后的路由信息设置路由属性
- 由一个或多个节点构成
	- 每个节点可包含多个条件语句，节点内的多个语句关系为与
	- 不同节点的关系为或
	- 若节点的匹配模式为 permit，匹配上 if－match 后它就执行后续的 apply 动作
	- 若节点为 deny 匹配上直接 拒绝通过
	- 若一个节点都没有匹配成功就都拒绝通过
