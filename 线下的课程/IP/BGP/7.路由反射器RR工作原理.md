- 引入路由反射器后存在两种角色
	- RR（Route Reflector）：路由反射器
	- Client：RR 客户端
- RR 会将学习的路由反射出去，从而使得 IBGP 在 AS 内传播无需建立 IBGP 全互联
- 对于 Client 本身不需要做任何配置，他不需要知晓网络中存在 RR
# 反射规则
- rr 从自己非客户端收到一条 IBGP 路由，他会将该路由反射给所有客户
- 从客户机收到一条路由他会反射给所有非客户，以及其他客户
- 从 EBGP 收到的遵循通告原则
# 属性
originator_ID
- RR 将一条 BGP 路由进行反射时会在反射出去的路由中增加 Originator_ID，这个 ID 值为始发路由器的 router ID
- 若 AS 内有多个 RR，则 Originator ID 由第一个 RR 创建且不被后续更改
