- 公认是所有路由器必须能够识别的属性
	- 公认必遵：必须在每个 Update 消息里
		- origen
			- IGP 标记 i,例如 network
			- EGP 标记 e 通过 EGP 学习到
			- incomplete 标记？ 通过 import－route
		- as_path
			- 类型 ：
				- AS_SEQNCE：将经过区域的 as 号依次写在左边
				- AS_SET:将来自不同 as 的路由进行聚合表示 as_path 为{x y}其中 x 与 y 不分先后顺序
			- 修改 as_path
				- 以实现对路由的影响
				- 通过 Router－policy
					- AS_PATH:100   apply as_path 300 additive
					- apply as_path 400 overwrite
					- apply as-path none overwrite
		- Next_hop
			- 路由器将自己的 BGP 路由通告给自己的 EBGP 对等体时将该路由的 Next_Hop 设置为自己的 TCP 连接源地址
			- 从 EBGP 收到的路由传递给 IBGP 对等体下一跳不变
				- 为了在 ma 网络环境中绕路，a 与 b 建立 EBGP，b 与 c 建立 IBGP
			- 收到某条 BGP 邻居，下一跳与 EBGP 对等体属于同一网段，将 下一跳不变
	- 公认任意：可能包括在某些 Update 消息里
		- local_Preference：可以告诉 AS 中的路由器，哪条是离开本 AS 的首选路径
			- 只在 IBGP 对等体传递
			- 在 AS 边界 import 方向修改 Loca_prefercence
			- 使用 bgp default local－perference 也可以修改，缺省为 100
		- Atomic_aggregate
- 可选不需要都被 BGP 路由器识别
	- 可选过渡：BGP 设备不识别此类属性，依然会接受该属性并通告给其他对等体
		- Aggregator
		- Community
	- 可选非过渡：BGP 设备不识别此类属性可以忽略该属性，且不会通告给其他对等体
		- MED
		- Cluster_List
		- Originator－ID
