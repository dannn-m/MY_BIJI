
| 分类       | 选项          | 用途                       |
| -------- | ----------- | ------------------------ |
| ipconfig | 无           | 显示IP、掩码、网关等基础信息          |
| ipconfig | /all        | 显示IP、掩码、网关、DHCP和MAC等详细信息 |
| ipconfig | /renew      | 更新DHCP配置，重新获IP           |
| ipconfig | /release    | 释放DHCP获得的IP地址            |
| ipconfig | /flushdns   | 清除DNS缓存信息                |
| ipconfig | /displaydns | 显示DNS缓存信息                |
